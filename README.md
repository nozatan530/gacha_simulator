# ガチャ確率シミュレーター

表示されている確率と、実際に引いた体感はどれくらいズレるかを体験できるシミュレーターです。

## 概要

このツールは、**復元抽出（ガチャモード）** と **非復元抽出（福袋モード）** の違いを直感的に学ぶための授業用教材として作られました。

確率論の授業や、消費者教育・メディアリテラシーの場面で、スマートフォンゲームのガチャと福袋という身近な題材を使って統計的な考え方を体験的に理解することを目的としています。

## 2つのモードの違い

| | ガチャモード（復元抽出） | 福袋モード（非復元抽出） |
|---|---|---|
| 仕組み | 毎回リセットして引く | 袋の中身が減っていく |
| 確率の変化 | 何回引いても変わらない | 引くたびに残りの確率が変わる |
| 全部引いた後 | 体感確率は表示確率に近づいていく（大数の法則） | 体感確率は必ず表示確率と一致する |
| 実例 | スマホゲームのガチャ | 福袋・トレーディングカードのパック |

ガチャ（復元抽出）では「100回引いても出ない」ということが起こりえますが、福袋（非復元抽出）では最後まで引けば必ず中身の比率通りに揃います。この違いを画面上で実体験できます。

## 使い方

1. `index.html` をブラウザで開く
2. スライダーで SSR・SR の排出確率を設定する（R は自動計算）
3. モードを選ぶ：**ガチャ（復元）** または **福袋（非復元）**
4. 「1回引く」「10連」「100連 / 全部引く」ボタンで抽選する
5. 表示確率と体感確率のズレを観察する

サーバーは不要です。ファイルをダブルクリックしてブラウザで開くだけで動作します。

## 技術構成

- **単一ファイル構成**：`index.html` のみ（HTML / CSS / JavaScript）
- **外部ライブラリなし**：依存パッケージ・ビルドツール不要
- **外部フォント**：Google Fonts（Noto Sans JP / Orbitron）をCDN経由で読み込み
- **動作環境**：モダンブラウザ（Chrome / Firefox / Safari / Edge）
